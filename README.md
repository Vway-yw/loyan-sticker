# 表情包生成

互动表情包生成 - 支持自定义文字和模板

## 安装

在 LoyanBot 插件商店中搜索「表情包生成」即可安装。

## 命令列表

| 命令 | 说明 | 使用环境 | 权限 |
|---|---|---|---|
| `/生成表情 <关键词> [QQ号]` | 用关键词生成表情包 | 群聊/私聊 | 所有人 |
| `/表情` | 表情包帮助（list/setpos/preview/scale/debug/setframe/framepreview/clearframe） | 群聊/私聊 | 所有人 |
| `/表情 list` | 查看所有关键词 | 群聊/私聊 | 所有人 |
| `/表情 setpos <关键词> <方向+数字>` | 微调位置 | 群聊/私聊 | 所有人 |
| `/表情 preview <关键词>` | 预览头像框位置 | 群聊/私聊 | 所有人 |
| `/表情 scale <关键词> <比例>` | 缩放头像大小(0.1~2.0) | 群聊/私聊 | 所有人 |
| `/表情关键词 add <关键词> <模板> [x,y,w,h]` | 添加关键词模板 | 群聊/私聊 | 所有人 |
| `/表情关键词 del <关键词>` | 删除关键词 | 群聊/私聊 | 所有人 |
| `/表情帮助` | 显示表情包帮助 | 群聊/私聊 | 所有人 |
